# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

This project is on Expo SDK 57 (React Native 0.86, React 19.2.x, New Architecture mandatory).
When adding dependencies, run `npx expo install <pkg>` so versions match the SDK.
Use `react-native-worklets/plugin` (NOT `react-native-reanimated/plugin`) as the last babel plugin.
`@expo/vector-icons` is NOT automatically included by `expo` since SDK 56 — install it explicitly if needed.
